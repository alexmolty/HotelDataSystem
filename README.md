# Hotel Data System 🏨

Консольное Enterprise-подобное приложение для управления бронированиями отеля. 

Проект разработан для демонстрации уверенного владения Core Java, принципов объектно-ориентированного программирования (ООП) и построения чистой, масштабируемой архитектуры без использования сторонних фреймворков.

## 🛠 Технологии и Архитектура

*   **Язык:** Java (Core)
*   **Архитектурный паттерн:** Layered Architecture (Разделение на Model, Service, CLI Interface).
*   **Паттерны проектирования:** Command / Item (для построения изолированных пунктов консольного меню).
*   **Хранение данных:** Кастомная реализация базы данных на основе Java Serialization (сохранение состояния объектов в бинарные файлы `.data`).
*   **Валидация:** Fail-Fast подход с использованием встроенных механизмов (`Objects.requireNonNull`) и строгой иерархией исключений (`IllegalArgumentException`, `IllegalStateException`).

## 🚀 Ключевой функционал

Приложение разделено на логические блоки управления:

1.  **Управление номерным фондом:**
    *   Создание и удаление типов номеров (RoomTypes) с настройкой стоимости и вместимости.
    *   Регистрация конкретных физических номеров (Rooms).
2.  **Управление гостями:**
    *   Регистрация новых гостей с валидацией email и возраста.
    *   Защита от удаления гостей, имеющих активные бронирования.
3.  **Система бронирования:**
    *   Поиск свободных номеров на заданные даты.
    *   Защита от пересечения дат (Overbooking protection).
    *   Автоматический расчет количества ночей и итоговой стоимости проживания.
4.  **Аналитика и отчетность:**
    *   Подсчет общего дохода и среднего чека.
    *   Определение самого популярного типа номеров (в том числе по возрастным группам гостей).
5.  **Persistence (Сохранение состояния):**
    *   Автоматическое сохранение всех данных при выходе из приложения.
    *   Восстановление базы данных при повторном запуске.
    *   *Примечание: При первом запуске (если файлы базы данных отсутствуют) встроенный генератор автоматически создаст тестовый набор данных (гостей, комнаты, брони).*

## ⚙️ Инструкция по запуску

Проект не требует внешних зависимостей или установленной СУБД.

1.  Склонируйте репозиторий на локальную машину:
    
```bash
    git clone [https://github.com/ВАШ_ЛОГИН/hotel-data-system.git](https://github.com/ВАШ_ЛОГИН/hotel-data-system.git)
    ```
2.  Откройте проект в любой современной IDE (IntelliJ IDEA, Eclipse).
3.  Запустите главный класс приложения:
    ```text
    src/hotel/app/HotelAppl.java
    ```
4.  При первом запуске в консоли появится уведомление о генерации тестовых данных. Следуйте инструкциям консольного меню для навигации по системе.

## 📁 Структура проекта

*   `hotel.model` — POJO классы предметной области (Hotel, Guest, Room, Booking).
*   `hotel.interfaces` — Контракты сервисов.
*   `hotel.service` — Реализация бизнес-логики и работы с файловой системой.
*   `hotel.items` — Контроллеры консольного интерфейса (наследники абстрактного `HotelItem`).
*   `hotel.generator` — Утилита для сидирования (seeding) базы данных случайными значениями.
